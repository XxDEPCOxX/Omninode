# Seguridad

Al exponer servicios de forma remota, la seguridad es crítica.

## Buenas prácticas del repositorio

- No subir contraseñas, claves API, certificados ni IPs públicas.
- Usar `.env` (ignorado por Git) y mantener `.env.example` con valores de ejemplo.
